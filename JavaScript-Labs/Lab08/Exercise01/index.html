How to turn JavaScript on/off (Chrome / Edge)

  1. Open Settings → Privacy and security → Site settings → JavaScript.
  2. Choose Don't allow sites to use JavaScript (or add this site to the "not allowed" list).
  3. Reload this page: the message changes to "You have JavaScript disabled".
  4. Quick alternative: open DevTools (F12) → Ctrl+Shift+P → type Disable JavaScript → reload.
